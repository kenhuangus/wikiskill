How WikiSkill works

WikiSkill co-evolves agent skills with a persistent knowledge base (wiki). Each evolution iteration runs the loop below; the wiki accumulates across all iterations and is never rolled back.

Raw layer immutable traces τ ~ π(x; S)
→
Wiki Maintainer root-cause analysis → patterns
→
Skill Proposer ReAct over wiki + traces → P
→
Gating accept iff R(T_val) > R_best

Algorithm 1 (per iteration k)

S₀ = ∅, W₀ = ∅;  R_best ← R_baseline(D_val, S₀)
for k = 1..K:
    if R_best == 1.0: break
    T_train,k ← rollouts of π with S_{k-1}      # skills injected, wiki hidden
    T_sample,k ⊂ T_train,k                       # ≤5 fails + ≤3 passes (App. C)
    W'_k ← M_WM(W_{k-1}, T_sample,k)             # wiki maintenance (patch edits)
    P_k  ← M_P(W'_k, S_{k-1}, T_train,k)         # ReAct proposer
    S'_k ← Apply(S_{k-1}, P_k)
    if R(T_val,k) > R_best:  accept; S_k ← S'_k; R_best ← R(T_val,k)
    else:                    roll back skills;  S_k ← S_{k-1}
    W_k ← Update(W'_k, P_k, R(T_val,k), a_k)     # harness writes skill-impact.md
return S_K, W_K

Glossary

S_kactive skill set (skills/)
W_kpersistent wiki (patterns, index, logs, skill-impact)
P_ksingle atomic skill proposal (create or patch)
M_WMWiki Maintainer agent (consolidates traces into patterns)
M_PWiki-informed Skill Proposer agent (multi-turn ReAct)
R_bestbest validation score; gating threshold (strict >)
R(·)accuracy metric on a trace set
